# 4.2.1 Levantamento de Requisito


## 1. Como os requisito foram levantados

Os requisito foram levantados por meio de uma entrevista com o responsável pela loja. Também foi analisado como a loja organiza atualmente os produto, clientes e vendas.

A entrevista foi sobre as principal dificuldade da loja e sobre o que o sistema precisa fazer.



❓ **Ficou para confirmar:** quais informação vai ser obrigatória no cadastro de produto, cliente e venda.



---

## 2. Da fala à necessidade

### F1 — Responsável pela loja



"Preciso controlar os produto, os cliente e as venda de forma organizada."

**Necessidade:** organizar as informação da loja.

### F2 — Responsável pela loja



"Preciso saber quais produto ainda estão disponível."

**Necessidade:** consultar o estoque dos produto.

### F3 — Responsável pela loja



"Quando uma venda acontece, preciso registrar para manter o estoque atualizado."

**Necessidade:** registrar as venda e atualizar o estoque.

### F4 — Responsável pela loja



"Preciso saber o que foi vendido."

**Necessidade:** consultar as venda realizada.

---

## 3. Histórias de usuário

### HU01 — Cadastrar produtos

**Como** administrador,

**quero** cadastrar produto,

**para** organizar os produto da loja.



**Veio da:** F1.

### HU02 — Consultar estoque

**Como** administrador,

**quero** consultar o estoque,

**para** saber quais produto tá disponível.

**Veio da:** F2.



### HU03 — Cadastrar clientes

**Como** administrador,


**quero** cadastrar cliente,

**para** manter seus dado organizado.

**Veio da:** F1.



### HU04 — Registrar vendas

**Como** vendedor,

**quero** registrar venda,

**para** manter o histórico dos produto vendido.

**Veio da:** F3.

### HU05 — Consultar vendas

**Como** administrador,

**quero** consultar as venda,

**para** acompanhar o que já foi vendido.

**Veio da:** F4.

---

## 4. Requisitos funcionais




### RF01 — Cadastrar produtos

O sistema deve cadastrar produto.

**Veio de:** HU01.


### RF02 — Consultar estoque

O sistema deve consultar o estoque.

**Veio de:** HU02.

### RF03 — Cadastrar clientes

O sistema deve cadastrar cliente.

**Veio de:** HU03.

### RF04 — Registrar vendas


O sistema deve registrar venda.

**Veio de:** HU04.


### RF05 — Consultar vendas

O sistema deve consultar as venda.

**Veio de:** HU05.

### RF06 — Atualizar estoque


O sistema deve atualizar o estoque.

**Veio de:** HU04.

---

## 5. Requisitos não funcionais

### RNF01 — Desempenho

O sistema deve responder as consulta em até 3 segundo.

### RNF02 — Acesso

O sistema deve permitir acesso somente aos usuário autorizado.
